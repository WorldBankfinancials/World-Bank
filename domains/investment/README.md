# Investment Domain

This domain handles investment portfolio management, including asset tracking, market data, portfolio performance, and investment operations for the banking platform.

## Structure
- `application/` - Use cases, commands, queries, handlers
- `domain/` - Entities, aggregates, repositories, services, events
- `infrastructure/` - Database persistence, cache, messaging, external adapters
- `interfaces/` - REST, GraphQL, gRPC, WebSocket, events
